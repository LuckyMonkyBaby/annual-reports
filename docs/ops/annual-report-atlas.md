# Annual Report Atlas

The application is a static white cover gallery: search company/ticker/year, click a cover, animate into twelve nearest color matches, and open its original PDF from the top-left toolbar. Ctrl+F / Cmd+F opens the application search, selects the current query; slash also focuses search. No framework, runtime server, account database, or browser persistence is required. Public image assets and `reports.json` live in `dist`; Vercel serves the static output. `dist/app.mjs` owns browsing and matching; `scripts/import_reports.py` owns discovery, issuer checks, PDF validation and first-page extraction. `scripts/color.py` owns palette extraction. No scheduled importer is configured.

## Source boundary

The collection targets published reporting years 2020–2026 across current S&P 500 tracking-fund issuers. All available quarterly SEC indices are inspected, then missing company-years are attempted against AnnualReports.com archive PDFs. Successful PDF signatures and first-page images are verified; missing, rejected and failed reports remain explicitly recorded in `scripts/coverage.json`. Discovery uses the SEC quarterly master index and ARS filing detail pages, including attached PDFs when the primary document is HTML. PDF signatures are validated before Poppler extracts page one. Company CIKs are limited to equity holdings in iShares IVV, a maintained S&P 500 tracking fund. This is a membership proxy rather than a licensed official S&P constituent list; the downloaded holdings date and source are stored in `scripts/universe.json` and `reports.json`. Index membership is the inclusion boundary, including foreign-incorporated index members. SEC incorporation metadata is retained when available. The archive is incomplete where no accessible designed PDF is found. The selection uses current membership, not membership at the report date.

`year` uses the first-page annual-report title when available, otherwise the SEC reporting-period year. Both `yearBasis` and the original `period`/`filed` dates remain in the data. This avoids labeling a 2024 report as 2025 simply because its fiscal year ends in January 2025.

On desktop the selected cover spans two columns and two grid rows, scrolls naturally, and returns to four columns beneath it. On mobile it occupies the full gallery width above the matches. Clicking the selected cover, the toolbar reset, or Escape restores browsing. Toolbar edges follow the first row’s rendered cover bounds on load and resize; narrow mobile rows keep enough space for the controls. Captions use the rendered image width and an inset; the custom search clear button replaces the native browser icon. Reduced-motion preferences disable the view transition.

## Image filtering and similarity

WebP decoding samples the rendered first page on a 32×32 grid. HSV pixels provide a coarse dominant hue while ignoring white margins; neutral covers fall back to grayscale. Plain pages with SEC commission and Form 10-K/Q headings and less than 8% chromatic content are excluded. Local Tesseract OCR checks uncertain monochrome pages because embedded PDF character maps can produce unreadable text; dense monochrome text pages are excluded too. This caught the user-reported Chipotle and Tapestry form pages while preserving the minimal Amazon cover. Monochrome designed covers without those form headings are preserved. This is a heuristic, not a model or aesthetic judgment; a designed SEC-form page may be excluded, while another plain text page may pass. Inspect new covers when growing the collection.

Nearest colors use squared RGB distance between dominant sampled colors, exclude the selected cover, and break ties by stable report ID. Matching is relative to this small collection; it does not infer layout or subject similarity.

## Operate

Requires Python 3, curl, Poppler (`pdftoppm`, `pdftotext`), WebP (`cwebp`, `dwebp`) and Tesseract OCR. Set `SEC_USER_AGENT` to an identifiable application and contact email if changing the operator; current contact was supplied by the user. The bulk importer uses four workers with a shared five-requests/second gate, retries transient failures twice, does not retry 404/410, and stays below SEC's documented 10 requests/second ceiling. Processed record metadata, first-page text and optional OCR output are cached outside Git in the OS temporary directory. Source PDFs are discarded after each report is processed; at most the active worker downloads are retained. Re-running resumes downloaded reports; delete the holdings/SEC ticker cache files to refresh membership.

```sh
python3 scripts/import_archive.py --start 2020 --end 2026
node scripts/check.mjs
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

The bulk import resumes through processed-record caches and deduplicates company/report-year pairs, preferring the latest SEC filing; archive records fill gaps after SEC processing. Each successful record has a real PDF URL, CIK, tickers, cover image, palette and source provenance. SEC records retain accession/file dates; archive records use null for dates and filing/form metadata that were not obtained. The importer atomically replaces the JSON manifest as it progresses; keep a running import local until complete. Failures are explicitly recorded rather than claimed as imported. Before archive backfill the importer probes a known PDF; connection failures block the batch and are recorded in `archiveStatus`, distinct from a missing or rejected document. On October 5 the SEC pass completed, while local downloads from AnnualReports.com failed with curl connection errors; the older-year backfill remains incomplete and can resume when connectivity returns. Source PDFs may become unavailable upstream; local first-page images remain readable, while original-document links depend on SEC availability. Remove a record and its cover and republish to withdraw it. There is no scheduled updater; this bulk run is user-authorized manual expansion.

## Verify

`node scripts/check.mjs` checks count, asset/source integrity, reporting dates, membership scope, ticker search and nearest-color behavior. `python3 scripts/check_import.py` checks the plain-form filter with colored and monochrome counterexamples. The browser check uses the parent workspace's installed Playwright, verifies image decoding, search/empty states, the PDF link, similar-cover navigation, Escape dismissal and mobile overflow, and records the actual UI outside Git. It requires the local server above. New checkouts need Playwright available to run that optional UI check; the product itself has no npm dependencies.

The user requested work outside Lobby. The application has an independent GitHub repository at luckymonkybaby/annual-reports on main, separate from the parent coding application's integration checkout. Vercel publishes `dist` with no installation or build step. Covers are precompressed WebP images served through the CDN with immutable cache headers; full PDFs are discarded after processing. Keep full PDFs, demo videos and temporary caches outside Git.

## Cost and speed

Page-one covers are rasterized once to 900-pixel JPEG intermediates in the temporary cache, then encoded once to quality-76 WebP files. Only WebP covers enter `dist`; full source PDFs are transient and intermediates remain outside Git. Vercel serves static files with no server functions, database or runtime image transformations. Immutable cover URLs include stable accession/source identifiers. When changing image encoding settings, generate a new filename/version to avoid stale browser caches. The first ten covers compressed from 997,039 to 527,202 bytes (47% reduction).

The browser renders 48 cards initially, appends more near the viewport with IntersectionObserver, and lazy-loads images. A bounded 800-pixel lookahead upgrades nearby images to eager loading and decodes them before they enter the viewport; new batches append 1200 pixels ahead so that buffer stays populated. CSS content-visibility:auto skips offscreen layout and paint while preserving the DOM and keyboard navigation. This is browser rendering virtualization, not a bounded DOM window; older batches remain mounted as the user scrolls. Search and palette comparisons run locally over the compact report manifest. CDN bandwidth and requests still count toward Vercel usage; caching does not make delivery free. Move the cover objects to separate object storage only if corpus size or measured traffic makes static deployment/transfer an actual constraint. The flat record manifest remains portable; UI cover URLs can be changed to a CDN without changing the source-PDF links.
